# Features (alpha)

A pure Python add-on that gives stock FreeCAD a familiar mainstream-CAD front end. FreeCAD itself is not changed; inside the program it is called FreeCAD.

- **Interface:** command ribbon with Features, Sketch, Surfaces, Sheet Metal, Weldments, Evaluate, Assembly, Drawing and Simulation tabs; property panels for features; feature tree with a rollback bar; view selector and heads-up view toolbar; right-click and gesture menus; keyboard shortcuts; Light and Dark themes.
- **Sketching:** inference snapping to edges, endpoints, midpoints, centres and intersections; automatic relations while you draw; smart dimensions; relation tools; Fully Define Sketch.
- **Part features:** extrude, revolve, sweep, loft, fillet, chamfer, shell, hole wizard, patterns, mirror, reference geometry, configurations, equations, mass properties and units.
- **Surfaces, sheet metal and weldments:** surface features; sheet metal (engine based on the FreeCAD SheetMetal workbench, LGPL); weldment members, trims, gussets, end caps and cut lists.
- **Assemblies:** mates, patterns, exploded views, interference and clearance checks, BOM, motion studies.
- **Drawings:** views, dimensions, annotations, tables (BOM, revisions, holes), sheet formats.
- **Simulation:** static studies with fixtures, loads, connectors, mesh and result plots, using FreeCAD FEM and CalculiX.
- **Design Library and Toolbox:** library parts and features; ANSI/DIN/ISO fasteners and Smart Fasteners.
- **MBD:** 3D annotations, datums, tolerances, Publish to PDF and STEP.
- **File handling:** extra import formats where their readers are available; clear messages when a file cannot be opened; lock files so a file open elsewhere opens read-only.
- **Optional downloads (not bundled):** Orca Slicer, Bambu Studio, PrusaSlicer for the 3D Slicer tab; Diotopo under Tools, Add-Ins.
- **Built-in guide:** F1 opens the page that fits what you are doing.

Known gaps are listed in `KNOWN-ISSUES.md`.
