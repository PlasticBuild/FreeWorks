# Share feedback

Alpha testers can use the private GitHub Issues link in their tester invitation.

Include the exact steps, what you expected, and what happened. If you can share a small example file, attach it. Add a FreeCAD screenshot and paste any relevant **Report view** text. Include the add-on version, FreeCAD version, and operating system version. Remove private information from files, screenshots, and logs before sharing.

| Severity | Meaning |
| --- | --- |
| S1 | Stops work |
| S2 | Wrong result |
| S3 | Dead or confusing control |
| S4 | Polish |

Use **Bug report** for incorrect behavior, **Feature request** for a missing capability, and **Look and feel** for layout, interaction, or visual feedback. For look-and-feel reports, describe the expected behavior in words and attach only screenshots from FreeCAD with assets cleared for sharing.
