# Share feedback

Everyone is welcome to open a [GitHub issue](https://github.com/PlasticBuild/FreeWorks/issues) for bugs, feature ideas, or feedback about the interface or documentation. Issues on this repository are public.

Include the exact steps, what you expected, and what happened. If you can share a small example file, attach it. Add a FreeCAD screenshot and paste any relevant **Report view** text. Include the add-on version, FreeCAD version, and operating system version. Remove private information from files, screenshots, and logs before sharing.

| Severity | Meaning |
| --- | --- |
| S1 | Stops work |
| S2 | Wrong result |
| S3 | Dead or confusing control |
| S4 | Polish |

Start your issue title with **Bug**, **Feature request**, or **Look and feel** so readers know what kind of feedback it is. For look-and-feel reports, describe the expected behavior in words and attach only screenshots from FreeCAD with assets cleared for sharing.
