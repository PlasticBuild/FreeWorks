10. Installing and troubleshooting

Before you install

  • FreeCAD 1.1.4 (1.1.0 or newer works; 1.1.4 is what FreeWorks is tested on). Use the official build for your system: the Windows installer or portable zip, the Linux AppImage, or the macOS disk image. FreeWorks needs no other build of FreeCAD.
  • Disk space: less than 100 MB for FreeWorks with its icons and the guide.
  • Write access to your FreeCAD user folder. FreeWorks lives there, and FreeCAD stores compiled copies of its files there on the first start, which makes every later start much faster.

Installing

During the private alpha the add-on is not in the Addon Manager: install it by hand, as the README in the zip says. The Addon Manager steps below are for the public release.

With the Addon Manager (recommended)

  1. Start FreeCAD.
  2. Choose Tools, Addon Manager.
  3. Search for FreeWorks, select it and click Install.
  4. Restart FreeCAD when asked.

By hand (also for offline computers)

  1. Get the FreeWorks zip on any computer and copy it across.
  2. Unpack it so that you have a folder called FreeWorks with InitGui.py directly inside it. If the zip makes a folder such as FreeWorks-main, rename it to FreeWorks.
  3. Move that folder into the Mod folder of your FreeCAD user data folder. Create Mod if it is not there.
SystemFolder
Windows%APPDATA%\FreeCAD\Mod
Linux~/.local/share/FreeCAD/Mod
macOS~/Library/Application Support/FreeCAD/Mod

Not sure where it is? In FreeCAD's Python console type App.getUserAppDataDir() and press Enter.

  1. Restart FreeCAD.

The first start

  • The first start takes a few seconds longer while FreeCAD compiles FreeWorks' files. Later starts are quicker.
  • On a new FreeCAD profile, FreeCAD's own welcome page appears first. Choose the FreeCAD Light or FreeCAD Dark theme there, or later in Options, Colors.
  • The window then changes to the FreeWorks layout: the ribbon at the top, the feature tree on the left, and the Welcome box. Press Ctrl+N to start a part, an assembly or a drawing.
  • Your FreeCAD settings are saved before FreeWorks changes them. Uninstalling puts them back.
  • Press F1 at any time for the page of this guide that fits what you are doing. Help, User Guide opens the contents.

  • Tools, Add-Ins has, below its table, "Check for updates automatically (once a day)" and, until Diotopo is downloaded, the Download Diotopo... button. A box explains that it is a separate program from its author's GitHub page, and the default answer is No. After the download the box shows Update Diotopo now. The ScanRuler and Diotopo tabs can be switched on and off in the ribbon's right-click Tabs menu.
  • Where downloads are kept: in FreeCAD's user data folder, not in the add-on's folder and not in Program Files. Uninstalling a download is deleting its folder there. A downloaded slicer's own settings, presets and sign-in are in a folder of their own beside it (slicer-data), so deleting the slicer's folder there does not touch a slicer installed on your computer.
  • Updates: the daily check only reads the release pages. Before Diotopo is downloaded nothing is checked for it. Afterwards the check can update it. A slicer is never downloaded by itself. Slicer Updates shows a count when a slicer you use has a newer release.
  • No connection: nothing is shown at start-up. A check you ask for says "no connection to GitHub" in plain words.
  • Licences: each extra is a separate program under its own licence (the slicers are AGPL-3.0). None of their code is part of the add-on.

Using FreeWorks offline

Everything for modelling works with no network: parts, sketches, assemblies, drawings, Options, and this guide (it is stored on your computer).

These things need the internet, and say so if they can't connect:

If a firewall asks whether FreeCAD may use the network, choosing Block does not stop any modelling feature.

Updating

With the Addon Manager: Tools, Addon Manager, then Update on FreeWorks, and restart. By hand: close FreeCAD, replace the FreeWorks folder, and start FreeCAD again. Your settings stay.

Uninstalling

With the Addon Manager, choose Uninstall. FreeWorks first puts FreeCAD's own settings back as they were before it was installed, then removes its own settings. By hand, remove the FreeWorks folder. FreeCAD's own toolbars stay in place (FreeWorks shows them again each time FreeCAD closes), FreeCAD's look then comes back at the next start, but FreeWorks' saved settings stay until you delete them in Tools, Edit parameters.

Your documents are ordinary FreeCAD files and open in any FreeCAD.

Common problems

FreeWorks doesn't appear after installing. Check that the folder is Mod/FreeWorks and that InitGui.py is directly inside it, not one folder deeper. Then open View, Panels, Report view and look for the warning and error lines written while FreeCAD starts (the add-on's own lines start with "FreeCAD:"). They name the problem.

The window looks half styled, or the old FreeCAD toolbars show. Restart FreeCAD once. FreeWorks applies its look at start-up. A theme change made while a sketch is open waits until you leave the sketch.

The first start is slow every time. FreeCAD can't save its compiled copies, because the Mod folder is read-only (often on managed computers or in a protected Documents folder). Give your user write access to the FreeCAD user folder, or install FreeWorks there rather than in a shared folder.

A tab, button or menu I need is missing. Right-click the ribbon and choose Customize. Every tab shows while Customize is open, and you can switch tabs back on. FreeCAD-only tools are on their own tab and in the menus; nothing from FreeCAD is removed.

A key does something else than I expect. FreeWorks sets its own keys while it is on (see chapter 9). For example, F1 opens this guide, not FreeCAD's online help, which is still in Help, FreeCAD. Change any key in Customize, Keyboard.

Snapping feels off, or no relations are added. Press F3 to make sure snapping is on (the status bar says which). Check that Ctrl is not held. In Options, Sketch, check that automatic relations are on. Very short lines take no Horizontal or Vertical relation on purpose.

Saving fails with "Permission denied" or "Cannot rename temporary file". Something else has the file open or blocks the folder. On Windows this is often Controlled Folder Access or another security tool watching Documents, or a sync program. Save to another folder, or allow FreeCAD in that tool's settings.

A file made with FreeWorks shows errors in plain FreeCAD. FreeCAD without FreeWorks reports "blocked import" lines for FreeWorks' features. The shapes are kept, but those features can't be edited until FreeWorks is installed again.

The slicer takes a long time the first time. The first read of a slicer's presets can take up to half a minute while your system reads thousands of small files. Later reads take under a second.

Something did nothing and showed no message. Open View, Panels, Report view, and in its right-click menu switch on Log messages. A step that failed quietly writes one line there with the file and the reason. Include that line when you report a problem.

FreeCAD feels slow with a very large assembly. In Options, Performance and Assemblies, use lightweight loading and the large assembly settings. Hide parts you don't need while working. Opening a big assembly again is quicker, because the drawn shapes of its parts are kept between uses.

FreeCAD uses more and more memory over a long day. The add-on frees the shape copies it keeps for a document when you close it, so memory should fall back after closing files (a test of 50 opens of a 20-feature part went from 1.1 GB to 0.6 GB, against 0.46 GB for FreeCAD alone). If it keeps growing, close and reopen FreeCAD and tell us which commands you used.

Turning or dragging the view stutters. Turn on Large Assembly Mode with Optimize image quality (it draws curves a little coarser). The add-on's own background work pauses while you turn the view or hold a drag, so a stutter that stays is worth reporting with the model size and the Report view lines.

I want to start again from the defaults. Each Options page has a Reset button. To reset everything, uninstall and reinstall with the Addon Manager, which removes FreeWorks' settings and puts FreeCAD's back.

Things that need another program

Slice or Preview says no slicer program was found. The Slicer tab needs a desktop slicer. With none, Slice, Preview, Export G-code and Send to Printer offer the download instead of doing nothing: answer Yes and the slicer is downloaded from the program's own release page, checked, and unpacked into FreeCAD's user data folder (never into the add-on folder). A slicer you installed yourself is used only when none was downloaded. With no network, open Slicer Apps and drop in a slicer zip or installer you already have. Until a slicer's own copy is there, its panel shows no All ... Settings buttons; they appear once it is (the list is built from that copy and kept in the slicer's work folder). The first read of a slicer's presets can take up to half a minute. See chapter 7.

A Sheet Metal button offers to install the SheetMetal add-on. FreeWorks carries the sheet metal engine it needs, and an installed SheetMetal add-on is used first. If neither can be loaded, each Sheet Metal button offers to install the free SheetMetal add-on with FreeCAD's Addon Manager. Say yes to install it, then restart FreeCAD; or reinstall FreeWorks (Addon Manager, Update or Uninstall and Install) to put its own engine back. The download is optional: nothing is installed unless you say yes, and parts and assemblies work without it.

A Simulation study stops or gives no result. Simulation runs on CalculiX. When a run stops, the message names what CalculiX found wrong (for example a missing material value). Fix the named thing, then run the study again. A normal solver error such as a bad mesh or a missing material is not retried and shows its usual message. If CalculiX itself crashes (an access violation on Windows, a segmentation fault on Linux), the add-on runs it again on one thread, because a crash like that is often a multithreading problem: the Report view shows the warning "CalculiX crashed (exit code N): running it again on one thread." and the study then solves as usual, with no setting to change and nothing different in the study. If the one-thread run crashes too, the study stops with "The solver stopped (exit code N)." Open View, Panels, Report view and switch on Log messages to see CalculiX's own lines, and include them if you report a problem. This covers every Simulation study run, SimulationXpress, Linear Dynamic and Topology studies. By default stock FreeCAD runs CalculiX on all the cores, unless the FEM preference sets two or more.

A Full slicer tab does not show the slicer window. The tab starts the slicer program and takes its window into the tab. A slow start is not a failure: the tab does not give up. It says the slicer is still starting and keeps looking for as long as the program runs. If the slicer is waiting for you (a message box the slicer shows), answer it and the window then joins the tab. If the program never starts, close the tab and open it again, start the slicer once on its own to see whether it runs at all, and check the Report view lines.

Questions and answers

Does FreeWorks change FreeCAD or my files? FreeCAD itself is not changed, and your documents stay ordinary FreeCAD files that open in any FreeCAD. FreeWorks saves FreeCAD's settings before it changes the layout, and uninstalling puts them back (Uninstalling).

Do I need to install anything else? No. Modelling, sketching, assemblies, drawings and this guide work with nothing else installed. A slicer, Diotopo and ScanRuler are optional (Optional downloads); ScanRuler needs a connection to open its page.

Does it work without a network? Yes, for everything you model with. The table in Using FreeWorks offline lists the few things that need the internet.

How do I get a key or a mouse gesture to do something else? Tools, Customize, Keyboard for keys and Mouse Gestures for the rings (chapter 8). Every default is listed in chapter 9. Press S for the shortcut bar and W to search for a command by name.

A sketch snaps where I do not want it to. What can I do? Press F3 to turn snapping off and on; the status bar says which (chapter 3).

Why is a control missing from a property panel? A control that cannot be used right now (and its label) is hidden and comes back as soon as it can be used, so a panel never shows a greyed-out control.

A dimension asks whether to make it a reference dimension. Why? It would over-define the sketch. Choose reference (driven) to keep the sketch as it is, or cancel the dimension.

The first start was slow. FreeCAD compiles the add-on's files the first time. Later starts are quicker (The first start).

Where do I find a downloaded slicer, and how do I remove it? In FreeCAD's user data folder, not in Program Files. Deleting its folder there removes it, and its own settings folder beside it stays unless you delete that too (Optional downloads).

How do I put every option back the way it was? Each Options page has a Reset button, and Customize has one Reset to Defaults. To reset everything, remove the add-on's settings group in Tools, Edit parameters, or start with a fresh FreeCAD profile (chapter 8).

Reporting a problem

Help, FreeCAD Rx collects what support needs: the FreeCAD and FreeWorks versions, your system and graphics, the installed add-ons and a rebuild timing. Copy it into your report on the project's issue page, together with what you clicked and what happened.
