FreeCAD User Guide

This guide covers FreeCAD with a command ribbon, a feature tree with a rollback bar, property panels for every feature, and sketch tools that snap and add relations as you draw. These come from the FreeWorks add-on, which is the name to look for when you install it (chapter 10). FreeCAD itself is not changed, and your files stay ordinary FreeCAD files.

Draft, 2026-11-18. Written for the first public release. Not shipped yet.

Words used in this guide

WordMeaning
RibbonThe band of tabs and large buttons at the top of the window
Feature treeThe list on the left: planes, origin, sketches and features in the order they were made
Property panelThe page that replaces the feature tree while a feature or tool is open: picks, values, OK and Cancel
Pop-up toolbarThe small see-through toolbar that appears next to the pointer after you pick something
RelationA rule a sketch keeps, such as Horizontal, Coincident or Tangent
SnapThe pointer jumping to a point, a curve or a direction while you draw

Help inside FreeCAD

This guide is built in: Help, User Guide opens it, and F1 opens the page for what you are doing. It works offline.
