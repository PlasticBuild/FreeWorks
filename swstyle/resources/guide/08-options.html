8. Options

Click the gear in the quick access row, or Tools, Options. The box has two tabs:

  • System Options apply to everything you do on this computer.
  • Document Properties belong to the open document and are saved with it (units, drafting standard, dimension and note styles).

Every setting in the box changes something. Settings are saved in FreeCAD's own user settings, so they survive updates of the add-on.

Document Properties

PageWhat you can set

UnitsMillimetre, centimetre, metre or inch unit systems, or Custom (any FreeCAD unit system, such as feet and inches); the length unit box is never greyed and picking another length unit picks Custom. With no document open, Options shows System Options only (there is no Document Properties tab). The Document Properties pages (Drafting Standard and its Annotations, Dimensions, Tables, DimXpert and Virtual Sharps pages, Detailing, Grid/Snap, Image Quality, Material Properties and Sheet Metal) have no greyed control, and every row you change is kept in the document and is there when you open it again. Length rows (arrow width and length, leader lengths, offsets, tolerances) show the document's unit, so an inch part reads 0.0394 in where a millimetre part reads 1 mm, and angle rows show degrees. Feature dimensions, the sketch Dimension panel (value, Override Units, text), MBD numbers and drawing dimensions write lengths in the document's unit, and a dual dimension shows the other unit. An assembly's Document Properties has Drafting Standard, Detailing, Grid/Snap, Units, Model Display, Image Quality (with Apply to all referenced part documents), Plane Display and Configurations. A drawing's has the Dimensions pages (Angle, Angular Running, Arc Length, Chamfer, Diameter, Hole Callout, Linear, Ordinate, Radius) and Tables pages (Bend, General, Title Block Table), whose rows are kept in the drawing; Line Style, Delete says why it did nothing for a built-in style instead of being greyed. Other System Options rows: FeatureManager has an Excel Design Table tree item, Spin Box has time increments, Collaboration rows hide while their parent is off, and Default Templates has an explaining line. Every System Options row whose parent box is off is hidden, not greyed.

Customize

Right-click the ribbon, Customize:

  • Toolbars and ribbon tabs: show, hide and order them; button size; text under buttons; tooltip style.
  • Keyboard: commands are listed by menu (All Commands, File, Edit, View, Insert, Tools, Help, Others, Macros and Selection). Pick a command and press the keys, or search for it. One click on a Shortcut(s) or Search Shortcut cell starts typing there, and the row stays picked after a change so Remove Shortcut acts on it. Column headings sort. Keys you change take effect at once.
  • Commands, Macro: drag New Macro Button onto a toolbar or ribbon tab, then choose the macro file, a name, a tooltip and an icon. Right-click the button later to edit or delete it.
  • Mouse Gestures: 2 (up and down, or left and right), 3, 4, 8 or 12 directions, and which command each one runs in parts, sketches, assemblies and drawings. One click on a Part, Assembly, Drawing or Sketch cell chooses the direction, and headings sort. Print Gestures Guides... prints the four rings and the list. Reset To Defaults asks whether to reset the mouse gesture guides or all customizations.
  • Menus: choose what the right-click menus show. "Show Customize Menu in shortcut menus" is here. The Others and Macros categories list the commands no menu has; Add puts one on the menu and position you choose, and Remove takes it off again. The Keyboard and Mouse Gestures tabs have a Description box under the list.
  • Quick Access Tools: on the Toolbars tab, two round buttons, Show in the Menu Bar and Show in the CommandManager; the second puts the quick access buttons beside the tab row (right of the floating tabs, or at the right end of the tab row when the tabs sit under the CommandManager). Reset to Defaults puts them back. Keyboard and Mouse Gestures have a Description box under the list, and Menus has Others and Macros categories (the commands no menu has): Add puts one on the chosen menu and position, Remove takes it off.
  • Six tabs, one Reset: Toolbars (with Lock CommandManager and toolbars at its foot), Shortcut Bars, Commands, Menus, Keyboard and Mouse Gestures. One Reset to Defaults at the foot, next to OK, Cancel and Help, resets the tab in front and asks what to reset. Shortcut Bars lists the toolbars beside a grid of buttons: pick Part, Assembly, Drawing or Sketch, and the bar shows in its own small window beside the dialog while the tab is in front.
  • Each reset button reads Reset to Defaults, and the Toolbars list is labelled Toolbars.

Going back to the defaults

Each page has a Reset button for that page. To reset everything, remove the add-on's settings group in Tools, Edit parameters, or reinstall with a fresh FreeCAD profile.
