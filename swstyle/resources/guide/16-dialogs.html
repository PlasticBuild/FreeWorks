16. Dialog boxes

The boxes you open from the File menu and from a few other places, one section each. The Help button in each box brings you to its section here. The commands you pick from the ribbon are in the command reference.

New document

File, New... (Ctrl+N) opens the New FreeCAD Document box.

  • Pick Part, Assembly or Drawing. A part is one solid: sketches and features in one body. An assembly holds parts and other assemblies placed together with mates. A drawing is a 2D sheet with views of a part or an assembly.
  • Click OK, or double-click the picture. Cancel keeps what you have.
  • The Novice view shows the three kinds. Advanced adds template tabs: one tab for each folder of templates, with the built-in Part, Assembly and Drawing on the Templates tab. Choose Large Icons, List or List Details for the tabs; the box remembers your choice. List Details shows each template's name, file, size and date.
  • The Preview box shows the picked template, or says there is no preview.
  • Tutorials lists step-by-step lessons.
  • A new part or assembly takes the Up axis chosen in Options, Default Templates (see chapter 8).
  • A new drawing asks for a sheet format and size first. Cancel there gives you the A (ANSI) Landscape format.

File properties (Summary Information)

File, Properties... opens the properties box for the open file.

  • Summary tab: Author, Keywords, Comments, Subject and Title, and under Statistics when the file was created and last saved, who saved it and with what.
  • Custom tab: a table of named properties (Property Name, Type, Value / Text Expression, Evaluated Value). Add a row, name it, choose its type and type the value. A bill of materials and a drawing's notes read these.
  • Configuration Properties tab (parts and assemblies; a drawing has none): the same kind of table for one configuration at a time. Pick the configuration from the list. Cut-list properties of a weldment show under their own heading.
  • OK keeps what you typed in all tabs; Cancel keeps nothing.

Page Setup

File, Page Setup... sets how the open document prints.

  • Use system settings or Use this document settings: with the second you can change the rest of the box for this file alone.
  • Resolution and scale: tick Scale to fit to fit the sheet on the paper, or type a Scale in percent.
  • Paper: the Size. Orientation: Portrait or Landscape.
  • Drawing color: Automatic, Color / Gray scale or Black and white.
  • Margins (in): Left, Right, Top and Bottom.

Print

File, Print... (Ctrl+P).

  • Document Printer: pick the Name of the printer. The line under it shows its status. If Windows lists no printer, the box says so; Save as PDF still writes a PDF file.
  • Beside the printer: Properties... (the printer's own box), Page Setup..., Header/Footer... (add the page number and total pages, date, time, file name, file path, sheet name or scale to the page) and Margins....
  • Document Options: Line weights... (the thickness each line weight prints with), Selection... (the Current screen image, or a Selection: the left, top, width and height of the view, in percent, printed at a Selection scale) and Scale... (Scale to fit, or a Scale in percent).
  • Print range: All sheets or Current sheet for a drawing, or Sheets: and the numbers, such as 1,3,5-7. A part or assembly has only All.
  • Number of copies, Print to file (a PDF or printer file you name), and Print background.
  • OK prints; Cancel prints nothing.

Print Preview

File, Print Preview... shows the page as it will print. Zoom In and Zoom Out change the size. Print... goes to the Print box, Page Setup... to Page Setup, and Close leaves. If the preview cannot be made, the box says why and Print... still works.

Find References

File, Find References... lists every file the open document uses.

  • The list has Name and In Folder columns.
  • Tick Include broken references to list links whose file is missing; they are marked as not found.
  • Tick Show nested view to list each document under the closest document that uses it: an assembly's parts under the assembly, a sub-assembly's parts under the sub-assembly.
  • Copy Files... copies the listed files to a folder you pick. Print... prints the list as a page; nothing prints until you click OK in the Print box.

Pack and Go

File, Pack and Go... gathers a document and everything it uses into one folder or a zip file.

  • Tick what to include: Include drawings, Include simulation results, Include Toolbox components, Include suppressed components, Include custom decals, appearances and scenes.
  • The table shows each file's Name, Save To Name, Save To Folder, In Folder, Size, Type and Date Modified. Nested view and Flat view change how the list is arranged.
  • Select / Replace... finds text in the Save To Names and replaces it, for a whole set of files at once.
  • Save to folder or Save to Zip file, and Browse... to pick where.
  • Flatten to single folder, Flatten to minimal folders or Keep full folder paths decides the folders that are made.
  • Email after packaging opens your mail program with the zip file attached.
  • Add prefix and Add suffix add text to every Save To Name.
  • Save packs the files; Cancel leaves everything as it was.

Export options

When you save as STL, 3MF, STEP or IGES, an Export Options box follows. Pick the File Format at the top; the options under it belong to that format.

  • STEP: Output as AP203, AP214 or AP242, and Export face/edge properties.
  • IGES: Output as Manifold Solid (type 186), Trimmed Surface (type 144) or Wireframe (type 110). IGES assembly structure: Save all components of an assembly in one file or Flatten assembly hierarchy.
  • STL: Output as Binary or ASCII, the Unit, and the Resolution: Coarse, Fine or Custom (then set the Deviation in mm and the Angle in degrees). Other ticks: Preview before saving file, Show STL info before file saving, Do not translate STL output data to positive space and Save all components of an assembly in a single file.
  • 3MF: the Unit, the same Resolution as STL, Include materials and Include appearances.
  • OK saves; Cancel returns to the Save box.

DXF / DWG output

Save As on a part with the type Dxf opens the DXF / DWG Output panel (see chapter 2); it is not the Export Options box.

  • Annotation views (the model's Front, Back, Left, Right, Top, Bottom and Current views, and any drawing views of the part), Hidden edges, and Separate files or one file with the views side by side.
  • Sheet metal shows for a sheet metal part only; Entities To Export and Output Alignment show only where they apply.
  • OK opens the DXF/DWG Cleanup window named after the part. Save writes the file; Cancel writes nothing.
  • The version and the other output settings are on System Options, Export, DXF/DWG (chapter 8). A drawing's own Save As, Options... shows the same settings.

Customize

Tools, Customize... is described in chapter 8.

Equations

Tools, Equations... opens Equations, Global Variables, and Dimensions.

  • The table has Name, Value / Equation, Evaluates to and Comments. Each group (Global Variables, Features, Equations) ends in an Add global variable, Add feature suppression or Add equation row to start a new one.
  • Filter All Fields narrows the list to what you type.
  • OK makes one Undo step named Equations: one Undo takes back the whole box and one Redo puts it back.
  • An equation that cannot be solved shows in red; move the pointer over it for the reason.
  • Equation edge cases: an equation that names the dimension it drives (D1@Boss-Extrude1 = D1@Boss-Extrude1 + 1) is refused as a circular reference, and a circle between two dimensions says that the equation refers back to itself. Deleting a dimension or a global variable that an equation uses does not fail the features after it: the equation stays, in red, and its dimension keeps its value. It is solved again as soon as the name exists, for example after Undo of the delete or when the variable is made again.
  • Automatically rebuild rebuilds the part after each change; Rebuild does it now. Angular equation units: Degrees or Radians. Automatic solve order lets the equations that use each other be solved in the right order.
  • Link to external file keeps the equations in a text file; Import... and Export... read and write one.
  • Undo and Redo in the box step through the edits; OK keeps them as one step in the document, Cancel drops them.

Confirm Delete

Pressing Delete on a feature or sketch asks first.

  • Delete the following item? names the item. And all dependent items: lists what is built on it, and Advanced shows each dependent under the item it was built on.
  • Tick Delete absorbed features to delete the sketch the feature was made from too (a sketch another feature also uses stays). Delete child features deletes the sketches and features built on it. Delete equations deletes the equations that use the deleted items.
  • Yes, Yes to All and Cancel answer. Don't show again deletes from then on without asking.
  • In a sketch, deleting an entity that has dimensions or is used outside the sketch asks the same way, with Replace Entity: it keeps the entity and starts Replace Entity on it, so what uses it moves to the new one.

Mass properties

Evaluate, Mass Properties opens the Mass Properties box.

  • Include hidden bodies/components counts the hidden items; Show weld bead mass adds the weld bead mass of a weldment; Report coordinate values relative to picks the coordinate system.
  • Recalculate reads the part again; Create Center of Mass feature puts a point at the centre of mass.
  • Override Mass Properties... is its own Undo step, and the overrides follow Undo and Redo (and come back with a configuration whose Delete is undone). It lets you type the mass and the centre of mass for the part, relative to a coordinate system you pick. The override belongs to the configuration it was set in; an older file's single override is kept by every configuration until one of them is changed, and renaming a configuration keeps its override and its kept values.
  • Print... and Copy to Clipboard send the report on.
  • Options... opens Mass/Section Property Options: the Units (Use document settings or Use custom settings, with length, mass and per-volume units, decimal places and Scientific Notation), the Material Properties (the density comes from the part's material; with none, right-click Material in the tree, then Edit Material), the Accuracy level from Lower (faster) to Higher (slower), Inertia Tensor (Positive Tensor Notation or Negative Tensor Notation) and Show output coordinate system in corner of window.
