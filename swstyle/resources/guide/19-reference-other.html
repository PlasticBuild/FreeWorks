File, quick access and selection

Welcome to FreeCAD

Opens the Welcome page: new and recent files, learning, alerts.

How to use it

  • Click it (or press Ctrl+F2) to open the Welcome box.

Shortcut: Ctrl+F2.

More: Quick access row.

New

Starts a new part, assembly or drawing.

How to use it

  • Click it (Ctrl+N). The New FreeCAD Document box opens: pick Part, Assembly or Drawing and click OK. The Advanced view adds template tabs. See New document.

Shortcut: Ctrl+N.

More: Quick access row.

Make Drawing from Part/Assembly

Makes a drawing of the active part or assembly with its standard three views.

How to use it

  • Open the part or assembly, then click it. A new drawing opens with the part's standard three views, Front, Top and Right. A part that has no file yet asks to be saved first.

More: Quick access row.

Make Assembly from Part/Assembly

Makes a new assembly and starts Begin Assembly with the active part picked.

How to use it

  • Open the part, then click it. A new assembly opens with Begin Assembly already showing the part picked. A part that has no file yet asks to be saved first.

More: Quick access row.

Open

Opens an existing document.

How to use it

  • Click it (Ctrl+O). Pick the file in the Open box. The Quick Filter buttons limit the list to parts, assemblies or drawings; Use Speedpak and Do not load hidden components show only while an assembly is picked.

Shortcut: Ctrl+O.

More: Editing and fixing.

Recent Documents

Lists the documents you worked on lately.

How to use it

  • Click it (press R over the 3D view) for the documents you worked on lately; pick one to open it. Save As puts a FreeCAD file at the top at once; exports are not listed.

Shortcut: R.

More: Opening, saving and exporting.

Save

How to use it

  • Click it (Ctrl+S). A document that has no file yet asks where to save it.

Shortcut: Ctrl+S.

More: Opening, saving and exporting.

Save As

Saves the active document under a new name or format.

How to use it

  • Click it. Type the name, pick the folder and the type. Options... shows only for a type that has options (see Export options). Include all referenced components saves the parts of an assembly too, with Add prefix or Add suffix.

More: Opening, saving and exporting.

Save All

Saves every open document that has changes.

How to use it

  • Click it. Every open document that has changes is saved; a document with no file yet asks where.

More: Opening, saving and exporting.

How to use it

  • Click it, give the copy a name and folder. You go on working in the original.

More: Quick access row.

Scale

Scales the part about its centroid, the origin or a coordinate system.

  • Scale Parameters: Scale about, Uniform scaling (one factor) or X, Y, Z factors.

Shell

Hollows the part, leaving walls of the given thickness; removed faces open it.

  • Parameters: the thickness; Faces to Remove: the faces that are opened; Shell outward adds the walls outside. Multi-thickness Settings: faces with their own thickness.

Sketch

The sketch being edited.

  • Draw with the Sketch tab tools; add relations and Smart Dimensions until the sketch turns black (fully defined). Exit Sketch (the corner check) keeps it; the cross discards changes.

Sketch Driven Pattern

Repeats features at the points of a sketch.

  • Selections: the point sketch; Reference point: Centroid or Selected point of the seed. Features and Faces / Bodies: what is repeated.

Slicing

Section sketches of the model at evenly spaced planes.

  • Slicing Plane: a plane or flat face to start from; Reverse direction. Slicing Parameters: the number of slices and the spacing. Options: one 3D sketch, or a 2D sketch per slice.

Split Line

Splits faces with a projected sketch, a silhouette or an intersection.

  • Type of Split: Silhouette (a direction and the faces), Projection (a sketch and the faces to split; Single direction, Reverse direction), Intersection (a plane or surface and the faces).

Surface-Extrude

Extrudes a sketch as a surface.

  • Direction 1: End Condition and depth; Direction 2; Cap ends when the profile is closed.

Surface-Knit

Joins surfaces into one surface body, or a solid when closed.

  • Selections: the surfaces and faces; Create solid when the result is closed; Merge entities; Gap Control: the gaps to close.

Surface-Loft

Lofts between profiles as a surface.

  • Profiles in order; Start/End Constraints; Guide Curves; Centerline Parameters; Options.

Surface-Offset

A surface offset from faces by a distance.

  • Offset Parameters: the faces or surfaces and the distance; Flip Offset Direction; a distance of 0 copies the faces.

Surface-Revolve

Revolves a sketch as a surface.

  • Axis of Revolution; Direction 1: the angle.

Surface-Sweep

Sweeps a profile along a path as a surface.

  • Profile and Path; Guide Curves; Options (orientation, twist); Start and End Tangency.

Sweep

Sweeps a profile along a path to add material.

  • Profile and Path: the profile sketch (or a circle made on the path), then the path.
  • Guide Curves: curves the profile follows as it sweeps.
  • Options: profile orientation and twist; Merge result.
  • Start and End Tangency: how the sweep leaves and arrives.
  • Thin Feature: a wall of the given thickness.

Table Driven Pattern

Repeats features at X-Y positions from a table.

  • Coordinate system: the origin of the table; Points: the X, Y of each instance (Browse to load, Save to keep). Geometry pattern; Features / Bodies to Copy.

Thicken

Turns a surface into a solid of the given thickness.

  • Thicken Parameters: the surface, the side (Side 1, Both sides, Side 2), the thickness; Merge result; Create solid from enclosed volume when the surface is closed.

Thickened Cut

Removes a thickened surface from the part.

  • As Thicken, cutting material; Feature Scope.

Thread

A cosmetic or cut thread on a cylindrical edge.

  • Thread Location: the circular edge, the start offset. Specification: type, size, pitch; Thread method: Cut thread or Extrude thread; right or left hand.

Trim Surface

Trims a surface with a sketch, plane or another surface.

  • Trim Type: Standard (a trim tool, then Keep or Remove selections) or Mutual (the surfaces trim each other). Surface Split Options: Split all, Natural, Linear.

Untrim Surface

Puts back the trimmed-away part of a face.

  • Selections: the faces or edges; Untrim the whole face or Extend edges; Merge with original.

Variable Pattern

Repeats a feature with dimensions that change per instance.

  • Features to Pattern: the feature. Create Pattern Table: a row per instance, a column per dimension; type the values, Update Preview to see them. Instances to Skip.

Variable Size Fillet

A fillet whose radius changes along the edge.

  • Items To Fillet: the edges; Variable Radius Parameters: a radius at each control point (click the callouts in the view), Set All / Set Unassigned, the transition (Smooth or Straight); add control points along the edge with the instances count.

Wrap

Wraps a sketch onto a face as embossed, debossed or scribed material.

  • Wrap Type: Emboss, Deboss, Scribe. Wrap Method: Analytical or Spline Surface. Wrap Parameters: the sketch, the face, the thickness; Reverse direction.
