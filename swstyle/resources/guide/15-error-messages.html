15. Error messages and what to do

This page collects the messages you are most likely to meet, what each one means and what to do next. A message that is not here usually says what to do in its own words; if it does not, copy it from the Report view (View, Panels, Report view) and send it with the part (Reporting a problem).

Simulation: the study will not run

These messages come up when you click Run This Study. Each one now says in plain words what is missing, once.

MessageWhat to do
"CalculiX was not found (<path>). Install it, or set its path in Edit > Preferences > FEM > CalculiX."The solver is missing, or the path points to a program that is not CalculiX. Install CalculiX or correct the path, then start FreeCAD again (chapter 10).
"The part is not held: add a fixture (Fixtures in the study tree, or the Fixtures Advisor), then run again."Add a fixture (chapter 11).
"No material is applied to the part: right-click the part in the study tree, Apply/Edit Material..., then run again."Apply a material.
"The material has no Elastic Modulus: edit the material and enter it, then run again." (the same for Poisson's Ratio)Open Apply/Edit Material and type the value. A library material is read only: copy it into Custom Materials to edit it.
"The mesh has no solid elements: a surface needs a shell thickness. Study a solid body, or give the surface a thickness, then run again."A surface or a thin sheet has no solid to mesh. Study a solid body, or give the surface a thickness.
"<part> has no geometry to mesh. Fix the part's failed features, then run again."A feature in the part failed and left nothing. Find the failed feature in the feature tree, fix it, then run again.
"CalculiX crashed (exit code N), so the study has no results. Run it again; if it crashes again, make the mesh coarser, or install CalculiX again."Run it again. If it crashes again, use a coarser mesh or install CalculiX again. (When CalculiX crashes on all cores the study first runs again on one thread by itself; the Report view says so.)
"The solver stopped: <line from CalculiX>"The line is CalculiX's own wording of what it did not like. Fix that and run again.
"The solver gave no result."Look in the Report view for lines from CalculiX, then run again.

Simulation: meshing

MessageWhat to do
"Meshing failed: Gmsh made no mesh of <part>." (or "Meshing failed:" followed by Gmsh's reason)The part may have slivers or self-intersecting faces. Repair the part, or try a larger or smaller element size.
"The mesh has N distorted element(s): a Jacobian at or below zero at the ... points. Try a smaller element size or a curvature-based mesh (Mesh Quality Plot > Jacobian shows them in red)."A high quality mesh with bent elements is refused. Make the elements smaller, or use a curvature-based mesh, and look at Create Mesh Quality Plot, Jacobian, to see where the bad elements are.
"The solver stopped because the mesh has distorted elements. ..."Mesh again with a finer density, or fix thin or sharp features in the part.
"<part> changed since it was meshed: meshing it again." (Report view)Not a problem. Run meshes the part again by itself.

A very thin sheet meshed as a solid can solve to an unrealistically large deflection without any message. If the displacement looks impossible, check the part's thickness and the displacement scale first.

3D printing

What you seeWhat to do
Send to Slicer says in red that the slicer is not there, and offers to download it.Download it from Slicer Updates on the 3D Slicer tab (chapter 7). Print3D stays open. In the Send list a slicer that is not downloaded shows "(not downloaded)".
A slicer "could not be started".The message says what to try.
Print3D says the part does not fit the printer (red).Use Scale to fit, turn the part with Suggest or a Bottom face, or tick Split to Fit.

Sheet metal

What you seeWhat to do
A sheet metal button opens a panel saying "Make a sheet metal body first".The part has no sheet yet. Use Base Flange/Tab or Convert to Sheet Metal in that panel.
A sheet metal button offers to install the SheetMetal add-on.No sheet metal engine loaded. Accept the offer (chapter 10).
Jog says "offset too small" when a Sketched Bend lip stands at the far end of the part.This was a fault: the jog measured to the lip. It now measures to the moved face nearest the jog line. If you still see it on an older copy, update, or make the offset larger.
Flatten stops with "list indices must be integers or slices, not NoneType" after an Edge Flange and a Closed Hem on the same side.This was a fault in the unfolder and is fixed: update to this build. If it still happens, send the part.
The Forming Tool panel opens and the part disappears.Fixed: the part now stays on screen so its faces can be picked. Update if you still see it.

Files and the rest

What you seeWhat to do
"File Not Found" when a part of an assembly is missingPress Esc to leave the box; FreeCAD stays open. Put the file back where it was and open the assembly again.
A value in the Modify box is refused and the old value is keptThe value would leave a line with no length or a circle with no radius. Type a value above zero.
